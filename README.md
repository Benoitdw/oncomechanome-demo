# OncoMechanome demo

The static demo served at https://oncomechanome.org.

`site/` is generated: it is the prerendered output of the OncoMechanome site, built and pushed by
`scripts/deploy_demo.sh` in the OncoMechanome repository. Do not edit it by hand. Every push to
`main` deploys it to GitHub Pages through `.github/workflows/pages.yml`.
